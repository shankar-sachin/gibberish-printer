# Gibberish Printer

A tiny browser app that generates random gibberish as either:

- **Characters** (up to 25,000,000)
- **Words** (up to 10,000)

## Usage

1. Open `/home/runner/work/gibberish-printer/gibberish-printer/index.html` in a browser.
2. Choose whether to generate by **Characters** or **Words**.
3. Enter the amount and click **Generate**.
4. Use **Copy** or **Download .txt** to export the result.

## Notes

- Character generation shows a preview for very large outputs.
- Download and copy actions use the full generated output.
